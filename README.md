# My Portfolio 🚀

A modern, dark, animated personal portfolio built with **Next.js 14** and **Tailwind CSS**.

## ✨ Features

- Smooth scroll-reveal animations and a typewriter hero
- Glassmorphism cards, gradient accents, animated background blobs
- Fully responsive (mobile → desktop) with a mobile menu
- Auto-deploys to **GitHub Pages** on every push (GitHub Actions)
- All content lives in one file: `src/data/portfolio.js`

## 🖊️ Edit your content

Open `src/data/portfolio.js` and update your name, roles, about text, skills,
projects, and experience. That's the only file you need to touch.

## 🧑‍💻 Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000

## 🌐 Deploy (GitHub Pages)

1. Push this repo to GitHub (branch `main`).
2. In the repo: **Settings → Pages → Source → GitHub Actions**.
3. Every push to `main` builds and publishes the site automatically.

Your site will be live at `https://<your-username>.github.io/<repo-name>/`
